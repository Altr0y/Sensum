## Sensum

# Naming conventions for commits: 
https://gist.github.com/qoomon/5dfcdf8eec66a051ecd85625518cfd13

Follow template:
[DEV-<number>] <type>(<optional scope>): <description>

Examples:
[DEV-4] feat(dashboard): add real-time temperature chart
[DEV-15] docs(readme): update local dev setup instructions
[DEV-16] build: upgrade .NET dependencies to latest stable
